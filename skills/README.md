# Skills

Este diretório contém processos reutilizáveis que ensinam agentes a trabalhar segundo as regras da operação.

## O que pertence aqui

- critérios;
- sequência operacional;
- checklists;
- políticas;
- formatos de saída;
- condições para pedir aprovação humana;
- critérios de sucesso e falha.

## O que não pertence aqui

- segredos;
- tokens;
- estado do CRM;
- regras específicas de SDK sem necessidade;
- chamadas concretas a fornecedores quando o domínio puder abstraí-las.

## Skills iniciais

```text
opportunity-radar/
opportunity-qualification/
commercial-followup/
client-request-triage/
project-handoff/
```

Cada Skill pode ter uma fonte canônica neste repositório e adaptações para os formatos usados por Claude, ChatGPT/Codex ou outros agentes.

## Princípio

Skill = **como executar**.

MCP/API = **como acessar dados e executar ações**.
